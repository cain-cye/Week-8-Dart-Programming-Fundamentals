## Scenario Description
This Dart console program builds on Week 7 store data by introducing decision-making logic:
- **Conditionals (`if/else`):** Categorizes purchases into Premium, Standard, or Small orders.
- **Loops (`for`):** Iterates through item prices.
- **Function:** `processItemPrice()` accepts parameters, calculates discounts, and returns the total.
- **Error Handling (`try/catch`):** Catches invalid negative prices without crashing.
